# 测试说明

## 可重复执行的检查

```powershell
.\scripts\build.ps1
.\scripts\Test-Integration.ps1
```

第一条命令构建发布二进制，运行原生表达式和维护调度单元测试。GitHub Actions 在 Windows runner 上执行这一部分。

第二条命令需要本机安装受支持版本的 Excel。它生成包含合成数据的工作簿，在独立的 Windows 桌面运行测试；用户桌面保持原样。测试使用独立的 COM 注册身份，结束后移除该测试注册。结果写入未纳入版本控制的 `test-results` 目录。

## v0.1.1 本机验证结果

验证环境为 Windows x64、Excel 16.0.20527.20196 x64，工作表缩放 90%。

| 检查 | 结果 |
| --- | --- |
| 原生表达式与调度单元测试 | 通过 |
| COM 加载项随 Excel 自动加载 | 通过 |
| 原生编辑状态接口 | 独立 Excel 进程正确返回 Ready |
| 输入、编辑、公式引用、状态查询失败 | 注入四种状态，维护暂停且保留原边界 |
| 目标工作簿激活时正在选取公式引用 | 延后范围读取，恢复 Ready 后启用 |
| 列查找或行查找暂时返回空 | 注入空结果，保留 15 列和原有行数，恢复后继续更新 |
| 删除最后一条记录、清空整个工作表、重新填写 | 收缩和扩展均通过 |
| 预填计数和记录编号列不延长内容边界 | 通过 |
| 关闭 Excel 事件后写入新记录 | 自动延伸到下一输入行 |
| 新输入行中心位置 | 视口高度的 53.6% |
| 未打开目标工作簿、切换到其他工作簿 | 维护定时器停止，后续观测区间回调为 0 |
| 返回目标工作簿与切换工作表 | 正常恢复 |
| 单列表格 | 通过 |
| 原生滚动位置采样 | 48 个样本均在边界内，允许 1 像素的取整差异 |
| 冻结表头顶部越界请求 | 显示位移停在冻结区域边缘 |
| 原生小数位移 | 移动阶段检测到连续的小数位移 |

原生测试通过 Composition 接口施加位置和速度更新，并读取合成后的位移、边界及裁剪。实际触控板手感由正常使用中的体验验证。

编辑状态与查找异常测试使用测试构建内的故障注入，执行真实 Excel 进程中的维护代码和尺寸更新链路。测试不发送键鼠输入；交互编辑场景的完整体验继续通过日常使用反馈验证。生产构建不包含这些注入接口。

## 维护开销的约束

- 非目标工作簿停止计时器。
- Excel 在后台时跳过原生位置读取和工作表扫描。
- 运动期间暂停维护，稳定后再检查。
- 末尾两行最多每秒读取一次，尺寸检查最多每五秒执行一次。
- 未变化的几何数据复用缓存，日常不写逐次边界日志。

测试构建包含原生性能计数器，可输出挂接函数的调用次数和耗时。发布构建不包含这些探针和计数器。
